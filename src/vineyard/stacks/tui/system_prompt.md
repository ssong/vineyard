## Required versions (current as of 2026)

- **Python 3.12** (LTS-equivalent through Oct 2028). Pin in `.python-version` and `pyproject.toml` (`requires-python = ">=3.12,<3.13"`).
- **Textual 0.80+** for the TUI framework

- **uv 0.5+** for dependency management (`uv.lock` committed)
- **pytest 8.x** + **pytest-textual-snapshot 1.x** for snapshot tests
- **ruff 0.7+** for lint + format

## Stack idioms (Textual current API)

- One `App` subclass that mounts `Screen`s; root screen is registered in `App.SCREENS` or pushed in `on_mount`
- One `Screen` subclass per logical view, in its own file under `<package>/screens/`
- Custom widgets in `<package>/widgets/`; reactive state via `reactive[T]`
- CSS in a single `theme.tcss` (or per-screen) loaded via `App.CSS_PATH`
- Bindings declared on the class via `BINDINGS = [Binding(...)]`; long actions use `@work(exclusive=True, group=...)`
- Modal flows use `ModalScreen[T]` returning a value via `dismiss(value)` and a callback on `push_screen(screen, callback)`
- Async I/O is fine — Textual runs on asyncio. Long network calls go through `@work` so the UI doesn't block.
- Use `self.notify(...)` for toasts, `Bell` for errors

## File layout

```
src/<package_name>/
  __init__.py
  __main__.py             # python -m <package>
  cli.py                  # Typer entry point: launches the App
  app.py                  # the Textual App subclass
  screens/
    __init__.py
    home.py               # main screen
    <feature>.py          # one per logical screen
  widgets/
    __init__.py
    <name>.py
  models/                 # Pydantic data models
  storage.py              # SQLite helpers (if persistent state)
  config.py               # pydantic-settings BaseSettings
  theme.tcss              # global styles
tests/
  conftest.py
  test_<screen>.py        # snapshot tests via pytest-textual-snapshot
  __snapshots__/          # generated by syrupy
pyproject.toml
.env.example
.python-version
README.md
```

## Required `pyproject.toml` shape

```toml
[project]
name = "..."
requires-python = ">=3.12,<3.13"
dependencies = ["textual>=0.80", "typer>=0.12", "pydantic-settings>=2.0"]

[project.scripts]
<command-name> = "<package>.cli:main"

[dependency-groups]
dev = ["pytest>=8", "pytest-textual-snapshot>=1.0", "ruff>=0.7"]
```

The `cli.py` Typer app exposes one subcommand (or just the default callback) that constructs the `App` and calls `.run()`. `python -m <package>` should also launch the TUI.
